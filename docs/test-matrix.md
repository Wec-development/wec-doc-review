# Requirement → test mapping

Every behaviour the brief says it will test, and the tests that prove it.

- **Paths:** relative to `apps/`.
- **Levels:**
  - unit: pure functions, no database;
  - integration (`*.int.test.ts`): real Postgres, the API through `app.inject`, the worker in-process;
  - e2e (`api/test/e2e/acceptance.e2e.test.ts`, scenarios S1–S7): HTTP in, a real background worker, real PDF parsing, the real SDK client replaying recorded model replies;
  - UI: React components in jsdom with a mocked API client.

How to run them: see [Tests](../README.md#tests) in the README.

## Do the tests catch real breakage?

Each guard below was broken on purpose, the API suite was run, and the file was restored byte for byte.

| Guard broken                                             | Tests that failed                                                                                    |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `locateEvidence` always finds the quote                  | 8: e2e S3; `llm-worker.int` v2-quotes-v1; `golden` fabricated quote and v1-vs-v2; `verify-fields` ×4 |
| `ON CONFLICT DO NOTHING` removed from the values insert  | 2: `worker.int` never duplicates; `carry-over.int` no duplicates                                     |
| …and the `(version_id, field)` unique constraint dropped | 3: `schema.int` unique; `worker.int` never duplicates; `carry-over.int` no duplicates                |
| Lease-expiry clause removed from the claim query         | 6: e2e S5 `SIGKILL`; `recovery.int` second worker; `worker.int` ×4                                   |
| `compareVersions` marks every field unchanged            | 15: e2e S2; `carry-over.int` ×3; `compare-versions` ×11                                              |
| `createDocument` runs the extractor inline               | 1: `documents.upload.int` never extracts inside the request                                          |
| Reviews allowed on non-current versions                  | 2: `values.review.int` 409; `carry-over.int` v1 read-only                                            |
